# Lazy Gains

A phone-friendly meal plan, shopping list, snack guide and weight tracker. It is one file (`index.html`) with no build step.

## Put it on GitHub Pages (free)

1. Sign in at github.com and create a new **public** repository called `lazy-gains`.
2. Choose **Add file > Upload files**, drop in `index.html` and `README.md`, then **Commit changes**.
3. Open **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/lazy-gains/`.

## Add it to your home screen

- **iPhone (Safari):** Share button, then **Add to Home Screen**.
- **Android (Chrome):** Menu, then **Add to Home screen**.

## Good to know

- Your ticked meals, basket, budget and weigh-ins are saved in your phone's browser. Clearing site data for the page erases them.
- Prices are estimates. To change them, edit the `SHOP` list near the top of the script in `index.html`.
- Meals and portions live in the `MEALS`, `SNACKS` and `WEEK` lists in the same place.
